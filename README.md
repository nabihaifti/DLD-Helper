A Digital Logic Design Helper with the following features:

1. Logic Simulator
   - Has basic gates (AND, OR, NOR, XOR, NAND, NOT)
   - Can save the circuit or blocks which can be reloaded between sessions
   - Can name inputs/outputs
   - Can create truth table of the circuit diagram

2. Function Simplifier
   - Simplifies expressions upto 8 variables
   - Generates truth tables of expression
  
3. K-Maps Solver
   - Can solve K-maps upto 6 variables
   - Visually represented grouping
   - Displays simplified expression
